# SpaceTrail

SpaceTrail uses the conventions of a macOS file browser. A narrow native sidebar leads directly to File, Cartelle, Cerca and Spazio. File opens on a sortable table. Cartelle keeps the same columns and adds a breadcrumb. Spazio puts capacity and a time series before two short rankings.

Use system typography, tabular numerals, native selection and keyboard focus, and an indigo accent for storage measurements. Use system surfaces and separators with support for both appearances. Keep help near the affected value or action. The window shrinks to a compact table and a vertically stacked overview.

The first-run window uses the supplied app icon and presents the access choice before indexing. Put Su disco first in the browser. Read file allocation and folder estimates from the index. The broker keeps the measurements current while the app is closed. Distinguish an estimate from a measured minimum. Keep logical size in a secondary column. Details show the exact byte count and the known shared space beside the results at wide sizes and below them in a smaller window.

File, Cartelle and Cerca remember their own list, compact or grid layout. Search opens with a grid of local Quick Look covers. Native sort and selection controls use the same index in every layout.
