# SpaceTrail

SpaceTrail follows desktop file browsers on macOS and Windows. A narrow sidebar leads to Files, Folders, Search, Map, and Storage. Files opens on a sortable table. Folders keeps the same columns and adds a breadcrumb. Storage puts capacity and a time series before recent growth and the largest items. The recent growth control switches between files and their containing folders. **Find Large Files** opens Files with the minimum size set to 100 MB.

Use system typography, tabular numerals, native selection and keyboard focus, and an indigo accent for storage measurements. Use system surfaces and separators with support for both appearances. Keep help near the affected value or action. The window shrinks to a compact table and a vertically stacked overview.

The first-run window uses the supplied app icon and presents the access choice before indexing. Put On Disk first in the browser. Read file allocation and folder estimates from the index. The broker keeps the measurements current while the app is closed. Label estimates and measured minimums. Keep logical size in a secondary column. Details show the exact byte count and the known shared space beside the results at wide sizes and below them in a smaller window.

Files and Search keep format and size filters close to the text field. Apply filter changes to the submitted query and let the user submit a new name with Enter or Search. On macOS, Files, Folders, and Search remember their own list, compact, or grid layout, with local Quick Look previews in Search. On Windows, use a sortable table and previews from the shell.
